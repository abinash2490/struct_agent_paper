# CSI Commercial CAE Benchmark Reference Outputs
===============================================

This directory contains the canonical raw tabular output reports generated by commercial structural analysis packages:
- **Computers and Structures, Inc. (CSI) SAP2000 v24.0.0 (Build 1865, 64-bit)**
- **Computers and Structures, Inc. (CSI) ETABS v21.0.0 (Build 2430, 64-bit)**

These output tables substantiate the benchmark reference values utilized in:
1. `research_paper/benchmarks/verify_cae_parity.py`
2. `research_paper/manuscript/tables/table_solver_verification.md`
3. Table 1 ("Numerical Solver Validation against Commercial CSI Engines") in Section 4 of the manuscript.

## Files
- `sap2000_sample_frame_results.txt`: Raw tabular results for `sample_frame.s2k` (2D portal frame under DEAD and MODAL analysis).
- `etabs_sample_frame_results.txt`: Raw tabular results for `sample_frame.e2k` (2D portal frame under DEAD analysis).
- `sap2000_3d_frame_results.txt`: Raw tabular results for `frame.s2k` (3D 3-story frame under DEAD, LIVE, and MODAL analysis).
